# NICE64 Browser v1.4.1

NICE64 Browser is an N64 web browser client for the NICE64 Network Pak. The ROM renders a compact NICE document while the Windows Bridge fetches, simplifies, and streams content through the Network Pak.

Features include Enter URL, provider-configurable Search Web, local Home, Favorites, Add to Home, persistent History and recent addresses, image support, clear options, staged bulk reads, and carrier-aware response acceptance for USB, TCP, and Product Quick Mode.

Version 1.4.1 is a release-identity-only promotion of the source lineage that produced the user-confirmed working Summercart v1.4.0 ROM. No Browser behavior changed during promotion.
