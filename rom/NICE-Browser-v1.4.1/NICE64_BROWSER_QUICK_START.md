# Quick Start — NICE64 Browser v1.4.1

1. Install NICE64 Universal Firmware v1.2.0 and connect the hardware to the host PC.
2. Copy `nice-browser-rom-v1.4.1-Release.z64` to a compatible flash cartridge.
3. Start `bridge-application/nice64-bridge-v1.8.0/application/PicoSwitchController.exe`.
4. Connect the NICE64 device and make the Network Pak module available.
5. Select the Network personality and explicitly select TCP or Product Quick Mode as the carrier.
6. Boot the ROM and select **Enter URL** to open a website.
7. Select **Search Web**, enter a query, and open a result.

If a website blocks automated access or returns an error, try another site or review [Troubleshooting](../../docs/TROUBLESHOOTING.md). Product Quick Mode does not silently fall back to TCP.
