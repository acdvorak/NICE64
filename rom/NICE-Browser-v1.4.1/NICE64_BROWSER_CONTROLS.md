# Controls — NICE64 Browser v1.4.1

- D-Pad: move link or menu focus.
- C-Up/C-Down: page up/page down.
- C-Left/C-Right: jump to top or bottom/next section.
- A: open the focused link or confirm a selection.
- B: cancel or close an overlay.
- Start: open or close the browser menu.
- Z: open the keyboard from a page; in Favorites, use the displayed command to add the focused favorite to Home.
- L/R: Back/Forward. Press both for Reload.

Home offers Enter URL, Search Web, Favorites, History, and Options. Options can clear History, Recent Addresses, and the in-memory page cache. Clear confirmations default to Cancel.

Images download after the page document. The text page remains usable while an image is loading; unavailable images leave the page intact.
