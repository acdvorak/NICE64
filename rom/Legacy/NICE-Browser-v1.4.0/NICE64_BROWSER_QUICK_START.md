# Quick Start

1. Install compatible NICE64 Network Pak firmware and connect the hardware to the host PC.
2. Copy `nice-browser-rom-v1.4.0-Release.z64` to a compatible flash cartridge.
3. Start `bridge-application/nice64-bridge-v1.4.0/application/PicoSwitchController.exe`.
4. Confirm the serial device is selected and the Network Pak module is available.
5. Boot the ROM and select **Enter URL** to open a website.
6. Select **Search Web**, enter a query, and open a result.
7. The Bridge log is written beside the executable. Review it for connection, module, and website-fetch diagnostics.

If a website blocks automated access or returns an error, try another site or review [../../docs/TROUBLESHOOTING.md](../../docs/TROUBLESHOOTING.md).
