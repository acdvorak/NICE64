# NICE64 Browser v1.4.0

NICE64 Browser is an N64 web browser client for the NICE64 Network Pak. The ROM renders a compact NICE document while the Windows Bridge fetches, simplifies, and streams content through the Network Pak.

Features include Enter URL, provider-configurable Search Web, local Home, Favorites, Add to Home, persistent History and recent addresses, image support, clear options, and trusted Bridge module packages.

Start with [NICE64_BROWSER_QUICK_START.md](NICE64_BROWSER_QUICK_START.md). Build instructions are in [NICE64_BROWSER_BUILD.md](NICE64_BROWSER_BUILD.md), and shared release details are in [../../docs/BUILD_MANIFEST.md](../../docs/BUILD_MANIFEST.md).
